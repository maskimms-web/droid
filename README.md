# OBD Speed — Android

Android-додаток українською для зчитування швидкості автомобіля через **Bluetooth Classic ELM327**.

## Функції
- Вибір уже спареного Bluetooth Classic пристрою (SPP UUID).
- Ініціалізація ELM327 та визначення протоколу через `ATSP0` і `0100`.
- Опитування швидкості `010D`, відповідь `410DXX`, значення `XX` у км/год.
- Автоматичне перепідключення з інтервалами 1–8 секунд, поки екран додатка відкритий.
- Скидання спідометра до `—` при втраті актуальних даних.

## Збірка APK
1. Відкрийте цю папку в Android Studio (JDK 17, Android SDK 35).
2. Дочекайтеся Gradle Sync (Android Studio може завантажити Gradle і залежності).
3. Виберіть **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Файл з'явиться у `app/build/outputs/apk/debug/app-debug.apk`.

## Використання
1. Вставте ELM327 у OBD-II роз'єм, увімкніть запалювання.
2. Спаруйте адаптер у системних налаштуваннях Bluetooth Android (часто PIN 1234 або 0000).
3. Відкрийте додаток, надайте дозвіл Bluetooth, виберіть адаптер, натисніть «Підключити».

## Обмеження
- Працює тільки з **Bluetooth Classic SPP**, не BLE та не Wi-Fi.
- Потребує підтримки стандартного PID `010D` автомобілем.
- Перепідключення працює лише поки додаток запущений, без фонового сервісу.
- APK у цьому пакеті відсутній: середовище генерації не має Android SDK/Gradle.
- Проєкт підготовлений, але не перевірений збіркою на реальному Android-пристрої.
- Налаштовуйте телефон до початку руху.

## Автоматична збірка APK через GitHub Actions (без Android Studio)
1. Створіть новий **порожній публічний або приватний репозиторій** на github.com (не додавайте README при створенні).
2. Розпакуйте ZIP і завантажте **вміст папки `OBDSpeedAndroid`** у корінь репозиторію. Важливо: прихована папка `.github/workflows` теж має потрапити в репозиторій. У вебінтерфейсі GitHub можна скористатися **Add file → Upload files**, але переконайтеся, що `.github/workflows/build-apk.yml` додано.
3. Відкрийте вкладку **Actions** → **Build Android APK** → **Run workflow**. Збірка також запускається при push у гілку `main` або `master`.
4. Дочекайтеся зеленого результату. Відкрийте запуск, у розділі **Artifacts** завантажте `OBD-Speed-debug-APK`.
5. Розпакуйте завантажений ZIP: усередині буде `app-debug.apk`. Перенесіть його на телефон і встановіть.

Це **debug APK**, підписаний тестовим ключем GitHub runner; підходить для особистого тестування, не для публікації у Google Play. GitHub Actions вимагає облікового запису GitHub та доступу до Інтернету. Проєкт не був перевірений фактичною збіркою у цьому середовищі.
