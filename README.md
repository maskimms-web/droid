# OBD Speed 1.2 — швидкість, акселерометр, g-force і відстань

Android-додаток українською для Bluetooth Classic ELM327.

## Функції
- Швидкість авто з OBD-II PID `010D`, км/год.
- Автоматичне перепідключення до ELM327.
- X, Y, Z та модуль сирого прискорення телефона в м/с² (із гравітацією).
- Оціночне **лінійне прискорення в g**: віднімання згладженої складової гравітації, графічна шкала 0–2 g. Це не калібрований автомобільний G-метр; нахили й вібрації телефона впливають на значення. Для точних поздовжніх прискорень/гальмувань потрібні фіксація й калібрування орієнтації телефона.
- **Пройдена відстань за поїздку**: інтеграція швидкості ECU за часом (трапеціями), кнопка «Скинути відстань». При пропущених відповідях, втраті зв’язку чи перервах понад 5 секунд відстань не додається. Значення є приблизним, залежить від точності ECU і частоти PID. Зберігається при повороті екрана, але після повного перезапуску додатка починається з нуля.

## Як зібрати APK у GitHub
1. Розпакуйте архів та завантажте **вміст папки `OBDSpeedAndroid`** у корінь GitHub-репозиторію.
2. Переконайтеся, що файл `.github/workflows/build-apk.yml` є у репозиторії.
3. Вкладка **Actions → Build Android APK → Run workflow**.
4. Після успішного завершення завантажте артефакт **OBD-Speed-debug-APK**.
5. Встановіть `app-debug.apk` на Android.

GitHub Actions використовує Java 17, Android SDK 35 та Gradle 8.9. Вихідний код також можна відкрити в Android Studio. APK не збирався локально в цьому середовищі.

## Golf 5 style (оновлення)
- Аналогова шкала 0–260 км/год у стилі панелі Golf V: темний циферблат, білі позначки, червона стрілка.
- Цифрове дублювання швидкості в центрі шкали.
- Дані швидкості залишаються з OBD-II PID `010D`, без зміни Bluetooth-логіки.
- Лічильник відстані, акселерометр та G-force збережено.
- Дизайн натхненний приладовою панеллю, без логотипів Volkswagen.

## Експериментальна навігація з паузою
- GPS використовується лише для початкових координат і курсу; курс береться з GPS bearing під час руху понад 2 м/с.
- Кнопка «Пауза навігації» заморожує координати і припиняє інтеграцію гіроскопа/швидкості.
- «Продовжити навігацію» запускає повторне калібрування гіроскопа (~100 вимірювань) на **нерухомому авто**. Під час калібрування координати не змінюються.
- Телефон треба повернути у **точно ту саму орієнтацію**. Якщо він повернувся під іншим кутом, курс стане неправильним.
- Переміщення автомобіля під час паузи НЕ враховується. Після такого переміщення потрібна нова GPS-фіксація/повторний старт.
- У цій версії **немає офлайн-карти, маршрутизації, map matching, відновлення GPS-корекції та надійної фонової навігації**. Це прототип координатного Dead Reckoning, а не готовий навігатор.
- Під час втрати OBD або призупинення Android-активності навігація не інтегрує час простою.
